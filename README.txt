EDUT — structure simple du site

Fichiers :
- index.html : page d’accueil avec sélection du niveau
- niveaux/ : une page HTML distincte pour chaque niveau
- matieres/ : une page HTML distincte pour chaque matière
- css/style.css : style commun
- js/app.js : menu mobile et recherche
- logo.png : ajoute ici ton propre logo avec ce nom exact

Pour tester :
1. Décompresse le dossier.
2. Place ton image de logo dans le dossier principal et nomme-la logo.png.
3. Ouvre index.html dans le navigateur ou importe tout le dossier dans ton éditeur en ligne.

Pages de niveaux incluses : 7ème, 8ème, 9ème année de base, 1ère, 2ème, 3ème et 4ème année secondaire.
Les pages matières sont des modèles de structure : ajoute les vrais cours, exercices et devoirs vérifiés correspondant à chaque niveau et section. Pour les classes secondaires, les matières peuvent varier selon la section.
